1. Pengertian Bootstrap
Bootstrap itu adalah salah satu framework CSS yang digunakan untuk mempermudah pembuatan tampilan halaman web agar lebih menarik dan lebih bagus.
2. Memasang Bootstrap
ada beberapa cara buat masang bootstrap ini, yaitu adalah menggunakan CDN, mengunduh file bootstrap dan yang terakhir adalah menggunakan package manager 
jadi bebas mau pake yang mana.
3. Grid dan BreakPoint
Grid itu adalah sistem tata letak Bootstrap yang membagi halaman menjadi 12 kolom, jadinya elemen website dapat disusun dengan rapi dan fleksibel.
4. Class Bootstrap
container, row, col, text-center, btn btn-primary, bg-success
5. Gambar Responsif
Agar gambar pada website responsif dan menyesuaikan ukuran layar perangkat, kita dapat menggunakan class img-fluid dari Bootstrap.
